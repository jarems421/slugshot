# Vision

## Confirmed

Slugshot is a new Roblox multiplayer creature-combat project. The current authorized milestone is the development foundation: Roblox Studio, Luau, VS Code, Git/GitHub and Rojo, with lightweight checks, agent procedures and Markdown memory. Use original or appropriately licensed intellectual property. No gameplay system is authorized by this milestone.

## Considering

Fast, skill-based PvP; collectible creatures; transformations; advanced movement; abilities; an underground world. Skiing, sliding, bunny hopping, cinematics, evolution and exploration are examples to investigate, not requirements.

## Unresolved

Movement model, camera, combat rules, creature identity, abilities, progression, game modes, multiplayer scale, art style and world structure. See [open questions](questions.md).

## Implemented/verified

Only development infrastructure. See [verification evidence](verification.md) for what actually passed; Studio runtime behavior is not implied by file existence or successful builds.
