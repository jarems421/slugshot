# Slugshot environment concept viewer snapshot

This is the complete original browser preview source and its fallback renders, preserved for the owner's requested main-branch backup on 2026-11-02. It contains the approved volcano study 05, reusable curled cave fern, proposed Burrow Exchange shop study 02 and three reusable cave flowers. Source Site commit: `e2774ca6b236ac47c2b8c612aaf18b75631d7308`. File hashes are in `snapshot-manifest.json`.

Run from the repository root:

```text
python -m http.server 8080 --directory docs/art/environment-preview
```

Open `http://localhost:8080/` for the volcano, `/?asset=shop` for the shop, `/?asset=fern` for the fern, and `/?asset=shop&flower=fan` (or `bell` / `orchid`) for the individual flowers. The GLB downloads, authored JS generators and no-WebGL fallback images are included. No compiler or hosted account is required for local viewing.

Authored Slugshot geometry/art and generated renders are original. Three.js r159 is vendored under its MIT licence in `THREE-LICENSE.txt`. Slugterra screenshots and public research images were references only and are not included. The snapshot contains no Site credentials, account settings, private Roblox mappings, restricted animation data or experience IDs.

This preserves browser concepts, not proof of Roblox import or production budgets. The volcano already has a separately authored lobby implementation; keep that newer game implementation when integrating. Shop/flower art approval, production optimization, NPC, purchases, final placement and Studio appearance remain as recorded in the asset notes.
