# Slug design catalogue

This is the shared home for every slug's design brief, source research, visual references, artwork, animation intent, gameplay ideas and verification. Add one entry per creature and keep this index current. Keep source references and rights notes separate from the original Slugshot deliverables. Never assume a fan model is licensed for reuse.

Copy the [new slug record template](template.md) for each future creature. Record:

1. **Confirmed:** owner instructions, distinguishing silhouette, palette, anatomy, personality and transformation behavior.
2. **Reference research:** links, author and license where known, access limitations and what was actually inspected. Reference images and other artists' models are not automatically reusable assets.
3. **Considering:** possible abilities, effects, rarities and gameplay role; do not treat ideas as approved mechanics.
4. **Implemented/verified:** own source and export paths, creator/provenance, tool version, rig ID, action names, generation settings and checks.
5. **Unresolved:** owner feedback, visual quality, import/runtime evidence, licensing or gameplay decisions.

Keep draft source and generated exports separately, as described in the [species guide](../species-guide.md). Do not publish or upload an asset solely because it appears in this catalogue.
