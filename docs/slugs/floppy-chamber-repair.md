## Implemented

- Created `assets/source/slugs/models/floppy/floppy-repaired.blend` as a technical variant; preserved `floppy.blend` and its paint. Surface-net junctions shared by four faces caused the winding defects. Local one-ring repair and boundary triangulation, numerical welding and normal recalculation remove them; new patch UVs are transferred from the original surface. Source material QA reports no errors. The exporter uses the repaired variant, repairs the low mesh before unwrapping/baking, then checks closed, consistently wound topology.
- Rebuilt the 8,800-triangle game model and its colour/normal/roughness maps. Eight bones, normalized weights with at most three influences and 12-second idle (zero seam drift and no scale channels) pass FBX reimport. The original high-detail baseline is intact.
- Loaded placement derives up/front from actual bones, scales uniformly, moves the complete model with PivotTo, then attaches its mesh parts while retaining their offsets. Clearance uses full width including antenna tips and leaves room for the idle. All duplicate named bone sets are animated when the importer gives different meshes separate skeleton copies. Runtime assertions check head-toward-muzzle and, after the owner correction, belly-down orientation.
- Gun grip geometry below its housing junction is 18% shorter, across all material meshes, with upper geometry preserved. Both the Floppy tool and the Rocklock blaster have a further uniform 0.88 scale multiplier. The native Rocklock stand-in's grip is shortened too. The input private blaster source was preserved; `tools/slugs/refit_floppy_blaster.py` reproduces the revised game mesh from the existing private JSON.
- Replaced the flat Highlight fill with one broad, dim inward-facing SurfaceLight (neutral warm white, brightness 0.45, range 0.75, no shadows). Pale-blue trim and its existing faint spill remain. This illuminates surfaces; final comfort/appearance remains an owner playtest gate. [Roblox SurfaceLight reference](https://create.roblox.com/docs/reference/engine/classes/SurfaceLight).
- Repaired colour loading after the first upload: Studio logs explicitly reported that SurfaceAppearance could not generate because textures were unavailable. The GLB itself had all seven embedded maps, so a good offline render did not prove imported image availability. Uploaded explicit Image assets for body colour/normal/roughness and both eyes' colour/roughness. Roughness is converted from glTF's packed green channel to separate grayscale maps. The uploader caches content hashes and keeps all reusable IDs private.
- Material-map setters require plugin security, so runtime code does not assign those protected properties. The private build contains three preconfigured SurfaceAppearance templates, cloned onto the three meshes by `FloppyAppearance`. Both loaders apply them. [SurfaceAppearance security reference](https://create.roblox.com/docs/reference/engine/classes/SurfaceAppearance); [supported Image uploads](https://create.roblox.com/docs/cloud/guides/usage-assets).
