# Inferno inspect studies v3

Open `Inferno-inspect-studies-v3.html` from the generated output. V3 adds a thinner, warmer mouth rim, overlapping facial acting, 27% larger Inferno and a sole grounded on the cap. The revised concepts already look at the holder as the gun rises, smoothly form an O-shaped mouth, sustain a moving volumetric flame, smile and use one spring hop back. V1 was rejected and is preserved separately. `mouth-and-fire-v2.gif` is a sampled motion preview; the HTML has full playback/orbit/scrub controls.

These are concept variants for owner review. The accepted Roblox gun animation and Inferno source meshes are untouched. Browser gun composition is an approximation without Roblox arms/viewmodel; review the chosen version in Studio only after selection.

Build from the creature worktree with `python tools/slugs/build_inspect_preview.py`. Requires the existing original Inferno base and blaster long-bevel GLBs, private material metadata (only colours are exported), and reviewed Three.js r159 files in `.tools/three-r159`. Hashes are pinned in the script. Do not substitute another version without review.

Three.js/GLTFLoader/BufferGeometryUtils: official mrdoob/three.js r159, MIT. Full licence is retained in the generated output and embedded in the standalone HTML. Source provenance and exact GLB/library hashes are in generated `provenance.json`. Reference screenshots are view-only and are not included in the artifact.
